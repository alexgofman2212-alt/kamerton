# Камертон

PWA-тренажёр для узнавания классической музыки на слух: звучит фрагмент, пять вариантов ответа, ранги, интервальное повторение. Vite + React + TypeScript, без сервера.

Перед работой прочитай `HANDOFF.md` — там состояние проекта, что не проверено и что делать дальше. Запуск и формат каталога — в `README.md`.

## Команды

- `npm run dev` — разработка; `npm run build` — проверка типов и сборка в `dist`; `npm run preview` — готовая версия с service worker.
- `npm test` — тесты ядра (vitest). `npm run e2e` — сквозной тест в браузере на собранной версии, звук подменён.
- `npm run catalog` — пересобрать `src/data/catalog.json` из `tools/catalog-src.json`. `catalog:analyze` и `catalog:selfhost` скачивают записи и требуют `ffmpeg`.

После изменений в `src/engine` запускай `npm test`, после изменений в экранах — `npm run build` и `npm run e2e`.

## Правила проекта

- Интерфейс, комментарии в коде и документация — на русском.
- `src/data/catalog.json` — результат сборки, руками не править. Править `tools/catalog-src.json` (или `tools/research/picks_data.py` и пересобрать через `picks.py`).
- В каталог попадают только записи с лицензией Public domain, CC0, CC BY, CC BY-SA. Список разрешённых — в `tools/build-catalog.mjs`; не расширять без решения заказчика.
- Логика обучения живёт в `src/engine` как чистые функции с тестами; экраны её только вызывают. Числа механики (пороги рангов, длины фрагментов, интервалы) — в `src/engine/rules.ts`.
- Прогресс читается и пишется только через `ProgressStore` (`src/engine/progress.ts`). Схема версионируется полем `v`; при изменении формата обновляй `normalize`.
- Запросы к Wikimedia: осмысленный `User-Agent`, строго ждать `Retry-After`, не подделывать браузер.
- Заказчик работает на Windows: команды для него давать под PowerShell.
