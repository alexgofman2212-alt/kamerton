# Камертон — контекст для Codex

Это отдельное приложение, не часть сайта Gofman AI Studio. Работайте с этим репозиторием как с самостоятельным проектом. Перед изменениями прочитайте README.md и CLAUDE.md, затем проверьте текущее состояние файлов. HANDOFF.md описывает исходную передачу работы и местами устарел: актуальное состояние определяется кодом и этим файлом.

## Назначение и принятые решения

- Русскоязычный PWA-тренажёр узнавания классической музыки на слух: фрагмент записи, пять вариантов ответа, ранги, усложнение, интервальное повторение, эпохи, композиторы и слабые места.
- Владелец выбрал публичный запуск без сервера. Прогресс пока хранится в localStorage на конкретном устройстве; перенос возможен через файл в настройках. Аккаунтов и синхронизации нет.
- Напоминания: пока приложение открыто, экспериментальный Periodic Background Sync на поддерживаемом Android и экспорт календаря ICS. Гарантированных push-уведомлений для закрытого приложения нет.
- Аудио загружается с Wikimedia Commons и требует интернета. Интерфейс PWA доступен офлайн после первого открытия.

- Проверено: npm test — 19/19; npm run build; npm run e2e — 20 проверок; локальная проверка PWA офлайн; опубликованный сайт отвечает HTTP 200, без ошибок JavaScript, service worker зарегистрирован; реальная запись воспроизводится в браузере (Wikimedia HTTP 206).

## Работа с кодом

- README.md содержит запуск, механику, структуру каталога и развёртывание. CLAUDE.md содержит правила исходного проекта; используйте их, если они не противоречат текущим файлам и запросу владельца.
- Стек: Vite, React, TypeScript, vite-plugin-pwa. Логика обучения в src/engine; интерфейс в src/screens; параметры механики в src/engine/rules.ts; доступ к прогрессу через ProgressStore в src/engine/progress.ts.
- Сохраняйте существующий дизайн и русскоязычный интерфейс, если владелец не попросит изменить их.
- После правок логики запускайте npm test; после правок интерфейса — npm run build и npm run e2e. Для изменений PWA и аудио есть tools/smoke-pwa.mjs и tools/smoke-audio.mjs.
- После публикации проверяйте GitHub Actions и живой сайт; сам push не доказывает успешный релиз.
- Не записывайте ключи и другие секреты в репозиторий. Команды для владельца давайте под PowerShell.
